## Admin can do
- Approve / reject **timesheets** (Approvals → Timesheets)
- Approve / reject **documents** (Approvals → Documents)
- Manage **students, contractors, employees, TTW** (Students)
- Create **programs** + **opportunities**
- Push **announcements** to all users

## Students can do
- Submit weekly **timesheets** → admin approves → download PDF
- Upload **documents** (W-4, ID, certs)
- Browse + enroll in **programs**
- Apply to **job opportunities**
- Complete **8 Learning Hub** lessons
- Update **profile + emergency contacts**

## Contractor onboarding (9 docs)
I-9 · W-4 · Direct Deposit · Photo ID · SSN · Background Check · CPR · HIPAA · Zero Tolerance

## TTW extras
SGA tracker ($1,550/mo) · VR counselor info · SSDI/SSI award letter

## Notes
- Portal sleeps after 15 min idle (free hosting). First load = ~30 sec wake.
- Mobile responsive — submit timesheets from phone.
- All approvals create an audit trail (who, when, why).
